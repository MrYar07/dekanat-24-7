# Изученные документы

Документы вуза автора, которые он предоставил 06.11.2026. В репозиторий не копируются: берём только идеи, а правила вымышленного «Меридиана» формулируем сами.

| Документ | Что взяли |
|---|---|
| Положение об академическом рейтинге студентов | блоки оценки 0,4 / 0,5 / 0,1; не меньше 3 срезов; правило 70% для автомата; штраф за пересдачу; премия преподавателя до +10; надбавка за научную и общественную работу до +5; конфиденциальность: студент видит только свои данные |
| Критерии поощрения научной и общественной работы | справочник видов достижений с максимумом баллов; подтверждение ссылкой или документом |
| Шкала соответствия оценок | 100-балльная шкала ↔ пятибалльная ↔ A–F |
| Памятка студенту по академическому рейтингу | рейтинг виден только в начале следующего семестра; выписки рейтинга выдают лично в отделе; студенты не понимают формулу (FAQ про «отличника на 80-м месте»); от рейтинга зависят скидки на обучение (пороги 90 и 95, без пересдач) |
| Положение об информационной системе «Электронный деканат» | оценки идут по бумажной цепочке «ведомость → кафедра → деканат → ручной ввод»; сроки сдачи ведомостей — конец семестра. Это объясняет, почему оценки видны поздно |
