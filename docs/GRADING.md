# Правила оценивания университета «Меридиан»

> Вымышленные правила вымышленного вуза для прототипа «Деканат 24/7».
> Общая идея (накопительный рейтинг из нескольких частей) вдохновлена рейтинговыми системами реальных вузов, но названия, коэффициенты, пороги и формулировки здесь свои.
> Все числа — настройки (`GradingSettings`), их можно менять без правки кода.

## Учебный год

Три триместра по 12 учебных недель, после каждого — сессия.

## Шкала

Всё оценивается из 100 баллов.

| Баллы | Оценка |
|---|---|
| 90–100 | отлично |
| 75–89 | хорошо |
| 60–74 | удовлетворительно |
| 0–59 | неудовлетворительно |

## Из чего складывается балл по дисциплине

### 1. Работа в триместре — 40%
- По каждой дисциплине не меньше **трёх срезов**: ориентиры — 4-я, 8-я и 11-я недели.
- Балл = среднее по срезам.
- Преподаватель может добавить **бонус за особые успехи — до +5**. Итог не больше 100.

### 2. Сессия — 45%
- Экзамен или зачёт, 0–100.
- **Автомат.** Если за работу в триместре набрано **75 и больше**, зачёт ставится автоматически с этим же баллом. Иначе студент сдаёт зачёт, и максимум за него — 74.
- **Пересдача.** Каждая пересдача снимает **10 баллов** с полученной оценки.

### 3. Вовлечённость — 15%
- Половина — **посещаемость**: считается автоматически по отметкам в журнале.
- Половина — **активность на занятиях**: оценка преподавателя в конце триместра.
- Это отличие «Меридиана»: посещаемость видна студенту в течение всего триместра, а не появляется сюрпризом в конце.

### Формула

```
Балл дисциплины = 0,40 × Работа в триместре + 0,45 × Сессия + 0,15 × Вовлечённость
```

До сессии кабинет показывает **прогноз**: вместо оценки сессии подставляется балл за работу в триместре, а вместо вовлечённости — текущая посещаемость и активность. Прогноз всегда подписан как прогноз.

## Рейтинг студента

```
Рейтинг триместра = среднее баллов всех дисциплин + бонус активности (до +4), но не больше 100
Годовой рейтинг   = среднее рейтингов триместров, без бонуса активности
```

## Бонус активности

Студент подаёт заявку с подтверждением (ссылка, программа мероприятия, публикация, грамота). Деканат проверяет и начисляет баллы, но не больше максимума за вид деятельности. Сумма за триместр — до 100 баллов, в рейтинг идёт с коэффициентом 0,04, то есть максимум +4.

| Направление | Вид | Максимум баллов |
|---|---|---|
| Наука | статья в научном журнале | 100 |
| | статья в сборнике, доклад на конференции | 60 |
| | участие в конкурсе научных работ | 50 |
| Творчество и медиа | выступление на межвузовском конкурсе | 40 |
| | материалы и репортажи для студенческих медиа | 20 за триместр |
| Спорт | соревнование за сборную университета | 40 |
| Сообщество | руководство студенческой организацией | 80 за триместр |
| | организация мероприятия | 50 |
| | помощь в проведении мероприятия | 30 |

## Что даёт рейтинг

| Условие | Привилегия |
|---|---|
| Рейтинг триместра от 85, без долгов | повышенная стипендия на следующий триместр |
| Годовой рейтинг от 90, без пересдач | рейтинговый грант — скидка 25% на обучение (для платной формы) |
| Годовой рейтинг от 95, без пересдач | рейтинговый грант — скидка 50% |
| Рейтинг триместра от 80 | отметка «В числе лучших на факультете» (видна только самому студенту) |

## Кто что видит

- Студент — только свои баллы, рейтинг и место на курсе.
- Преподаватель — баллы своих групп по своим дисциплинам.
- Деканат — данные студентов своего факультета.
- Публичных списков с ФИО нет.
